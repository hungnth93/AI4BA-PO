# AI4BA-PO

AI skills, templates, workflows, and reference materials
for Business Analysts and Product Owners.

## Repository structure

- `skills/ba` - Business Analyst skills
- `skills/po` - Product Owner skills
- `references` - Shared reference materials
- `templates` - Reusable document templates
- `examples` - Example outputs

## Goal

Maintain a single source of truth for AI-assisted BA/PO workflows
that can be reused across ChatGPT, Cursor, Codex, and other AI tools.
